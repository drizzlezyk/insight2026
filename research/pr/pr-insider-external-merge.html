03 · Reading

这意味着什么

  • 内部 PR 是自助合并，不是“同事代合”。全部内部 98.6%，官方名单 96.8%，名单外有权限 99.4%。独立合入只有 371 个，且其中 167 个还是机器人。
  • 外部 PR 是“等人代合”。外部 3,264 个 PR 的自合率为 0；主要由 obviyus（1,630）、steipete（768）和机器人（292）合入。
  • 官方名单解释不了实际权力结构。官方 Foundation / Core 只占 28.3%；steipete 一人在名单外贡献 59.9%。讨论“社区内部”时，必须区分官方身份和实际合入权限。
  • 自合 ≠ 没有 review。ClawSweeper、CI、其他维护者可能已经审过；这里只反映最后点“Merge”的账号。若目标是强制独立复核，需要显式设计第二人合入或 review 门禁，而不是依赖习惯。
04 · Method

口径与边界

时间窗口：按 merged_at 统计 2026-09-13 至 2026-11-13（含边界，UTC），共 62 天；包含窗口前创建、窗口内合并的 PR。

内部判定（行为代理）：PR 的 head 仓库 = base 仓库（同仓库分支，说明有 push 权限）∪ 作者在窗口内作为 merged_by 出现（说明有 merge 权限）∪ 作者在官方 Foundation / Core 名单（openclaw.org/people，43 个 GitHub 账号，其中 29 人出现在合并 PR 作者里）。其余人类作者判为外部。

自合判定：PR 作者 login 与 merged_by login 忽略大小写后严格相等。它不等于“无 review”，只表示最后执行合并的账号。

机器人：剔除 roboclaw-bot 2,909、openclaw-mantis 617、tideclaw-bot 41、dependabot 10、openclaw-macos-publisher 8、clawsweeper 4、ycmjbot-bot 1、jarvis-stephens-bot 1，共 3,591 个 PR。GraphQL 有时把 openclaw-mantis[bot] 返回成 openclaw-mantis，已按 REST 的 Bot 类型修正。

稳健性：只用同仓库分支是 87.8%；只用 merged_by 是 88.8%；加上 author_association 的 MEMBER / COLLABORATOR / OWNER 只多 1 个 PR（88.9%）。外部作者中 99.3% 是 CONTRIBUTOR/NONE，1 个 MEMBER；17 个外部 PR 的 fork 已删除，按外部计。少量疑似 agent 账号（<35 个 PR）可能仍有噪声。

限制：GitHub 不向无 push 权限的 token 暴露 collaborator 列表，所以“有合入权限”是行为代理，不是权限 API 的精确值；同仓库分支说明 push，但分支保护下未必人人可 merge。一个只从 fork 提交、且窗口内没合过任何 PR 的写权限持有者，可能被误判为外部。

数据：GitHub GraphQL Search · repo:openclaw/openclaw is:pr merged:2026-09-13..2026-11-13，逐日分片并分页；33,032 个已合并 PR，按编号去重。官方名单：openclaw.org/people（30 Core Maintainers + 13 Foundation，抓取于 2026-11-17）。
